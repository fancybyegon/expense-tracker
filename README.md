# Expense Tracker

A simple and intuitive **React-based Expense Tracker** application to help users manage their finances by recording, categorizing, and analyzing their expenses. The app allows users to add, view, search, and delete expenses with a clean and responsive user interface.


## Features
- **Add Expenses**: Input expense details including name, description, category, amount, and date.
- **View Expenses**: Display expenses in a table with columns for expense name, description, category, amount, date, and actions.
- **Search Functionality**: Filter expenses by description using a search bar.
- **Delete Expenses**: Remove individual expenses from the list.
- **Responsive Design**: Optimized for both desktop and mobile devices.


## Technologies Used
- **React**: JavaScript library for building the user interface.
- **Tailwind CSS**: Utility-first CSS framework for styling.
- **React Icons**: For the search icon (`IoSearchOutline`).
- **JavaScript (ES6+)**: Core programming language for logic.
- **Vite**: Build tool for development and bundling.
